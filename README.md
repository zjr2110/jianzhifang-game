# 剪纸坊

剪纸坊是一款以中国传统剪纸为题材的安卓手机游戏。玩家选择纸张与折法，在折叠后的纸上剪刻，展开后得到对称的剪纸作品，作品经评分后可参与拍卖，所得铜钱用于解锁新的纸张、折法与纹样。

## 功能

- **折纸剪纸**：支持不折、对折、四折、五角折、六角窗花、八折团花、十六折、连续拉花 8 种折法与 9 种纸张；提供剪刀、直线刻刀与传统纹样印章；剪断的纸片自动掉落，展开时逐折翻开。
- **照样剪纸**：内置 13 张样稿（含生肖系列），按样稿虚线剪刻，完成后给出吻合度评分与漏剪、多剪对照。
- **照片变样稿**：对剪纸照片进行分割与对称性检验，识别其折法并生成可剪的样稿，识别过程以动画形式呈现。
- **剪纸图纸**：作品与样稿可导出为 A4 图纸，包含折法步骤与 1:1 实际尺寸剪样，用于真实纸张剪纸。
- **拍卖与记录**：作品按评分估价并参与拍卖；提供铜钱收支明细、成交记录与统计。

## 运行环境

- 引擎：Godot 4.7（GL Compatibility 渲染）
- 平台：Android，竖屏

## 目录结构

| 目录 | 内容 |
|:--|:--|
| `scenes/` | 主场景 |
| `scripts/` | 游戏逻辑：剪纸模型、折法几何、连通分析、照片识别、图纸导出等 |
| `scripts/screens/` | 各页面：首页、选纸、剪纸台、展开结果、拍卖、样稿、记录 |
| `scripts/ui/` | 界面组件：底部面板、开屏动画、识别过程动画、明细面板等 |
| `shaders/` | 纸张、木纹桌面、教学聚光圈着色器 |
| `assets/` | 图标、开屏贴图、音效、示例照片 |
| `templates/` | 内置样稿（png + cfg） |
| `tools/` | 样稿、音效、开屏贴图的生成脚本（Python） |

## 打开与导出

1. 使用 Godot 4.7 打开 `project.godot`。
2. 在编辑器中安装 Android 导出模板，并配置 Android SDK 与签名密钥。
3. 在“项目 → 导出”中选择 Android 预设，导出 APK。

`tools/` 下的脚本需要 Python 3 及 Pillow、numpy。
